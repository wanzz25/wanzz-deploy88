03 Deployment Target

Repository terpilih: belum dipilih
Tombol di bawah ini memanggil backend asli (/api/vercel atau /api/netlify) yang membuat deployment lewat REST API resmi memakai API key server — bukan webhook. Pastikan token sudah diatur — lihat README-BACKEND.md.

Kosongkan untuk pakai subdomain otomatis dari nama project (mis. nama-project.vercel.app). Kalau diisi, domain custom ini harus sudah terdaftar/terverifikasi di akun Vercel/Netlify kamu — Wanzz Deploy hanya memasangkannya ke deployment yang baru dibuat, bukan membeli/mendaftarkan domain baru.

04 Upload Project

Paste HTML langsung, atau upload file/ZIP dari perangkat kamu (bisa pilih beberapa sekaligus) — sistem otomatis mengekstrak ZIP. Klik ✎ untuk edit isi file, klik nama file untuk ganti nama/path-nya, lalu jadikan repository atau push langsung ke GitHub.
