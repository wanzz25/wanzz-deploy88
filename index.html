Tentang Wanzz Deploy

Platform demo deployment modern, dibangun untuk menunjukkan bagaimana pengalaman "deploy tanpa ribet" bisa terasa — cepat, rapi, dan tanpa perlu login.

Apa itu Wanzz Deploy?

Wanzz Deploy adalah antarmuka deployment yang terhubung ke backend sungguhan: pilih repository dari akun GitHub yang tersambung, tekan tombol deploy, dan server akan membuat deployment asli lewat REST API resmi Vercel/Netlify memakai API key — bukan webhook. Console log menampilkan progres nyata dari permintaan itu.

Bagaimana cara kerjanya?

Tidak ada proses pendaftaran. Pengguna cukup menekan tombol Quick Access, melewati halaman loading singkat, lalu masuk ke dashboard. Panel status API menampilkan kondisi koneksi ke GitHub, Vercel, dan Netlify. Panel Upload Project memungkinkan pengguna menaruh file, paste HTML mentah, atau upload beberapa file/gambar sekaligus, mengedit isinya di dalam browser, lalu memilihnya sebagai repository yang siap dideploy — atau push langsung ke GitHub.

Apakah ini gratis?

Ya — Wanzz Deploy 100% gratis digunakan sebagai demo/showcase. Tidak ada biaya, tidak ada akun berbayar, dan tidak ada watermark tersembunyi. Ini adalah proyek open showcase dari Wanzz Dev.

Catatan penting

Frontend (halaman ini) berjalan di browser, dan proses upload/edit/ekstrak file tetap dilakukan secara lokal di perangkat kamu. Tapi tombol Deploy sungguhan memanggil backend (folder /api, dipecah jadi github.js, vercel.js, netlify.js) yang memakai API key (GITHUB_TOKEN, VERCEL_TOKEN, NETLIFY_TOKEN) langsung ke REST API resmi masing-masing. Token/secret tersimpan di server — tidak pernah ada di kode yang dikirim ke browser. Lihat README-BACKEND.md untuk cara menghubungkannya.
